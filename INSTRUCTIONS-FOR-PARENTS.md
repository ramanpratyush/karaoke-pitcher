# Karaoke Pitch Shifter — How to use it

This changes the key of a YouTube karaoke video, up or down, without making
it faster or slower. You get back a video file that plays like the original,
just in a different key.

## First time only: download it

1. Go to the download link you were given.
2. Click **KaraokePitchShifter-Windows.exe** to download it.
3. Your browser may say the file "isn't commonly downloaded" or similar.
   Choose **Keep** or **Keep anyway**.

That downloaded file *is* the program. There is nothing to install. Put it
somewhere easy, like your Desktop.

## Windows will show a blue warning the first time

When you open it, Windows may show a blue box saying
**"Windows protected your PC"**.

This happens because the program is not signed with a paid certificate. To
continue:

1. Click **More info**.
2. Click **Run anyway**.

You should only have to do this once.

If your antivirus removes the file instead, it is a false alarm — these
small homemade programs often get flagged. You may need to allow it in your
antivirus, or ask Pratyush.

## Using it

1. **Double-click** the program. The first start takes about 10–20 seconds,
   because it unpacks itself. Later starts are quicker. Only click once.
2. In YouTube, copy the address of the karaoke video.
3. **Paste** that address into the box.
4. **Drag the slider** to the key you want:
   - Drag **left** for a **lower** key (easier for lower voices)
   - Drag **right** for a **higher** key
   - Each step is one semitone. Most people want 1 or 2.
5. Click **Pitch Shift!**
6. Wait. A short video takes under a minute; a long one takes longer.
7. It will ask **where to save** the new video. Pick a folder you will
   remember, then click Save.
8. Open the saved file to sing along.

## If it says it cannot download the video

The message will usually say the program **needs an update**. YouTube changes
things every few months, which stops the old version from working.

**The fix:** go back to the same download link and download it again. A fresh
version is built automatically twice a month, so a working one is normally
waiting for you. Delete the old file and use the new one.

If a fresh download still fails, tell Pratyush.

## Other things that can go wrong

- **"It did nothing when I clicked"** — give it 20 seconds on first launch.
- **A private, members-only, or age-restricted video** cannot be downloaded.
  Try a different karaoke video.
- **Very long videos** (over 15 minutes) take a while. It is still working
  even if it looks still.
